- 设计灵感平台 + 轻工具产品
- 黑白灰主导
- 低饱和蓝灰点缀
- 留白充足
- 卡片系统统一

## 首页

- Hero + 搜索
- 专题入口
- 热门单页
- 最新单页
- 页型入口
- 场景入口

- 按页型找页
- 按场景找页

## 图标方案

- 线性图标
- 使用 `lucide-react`
- 保持单色和轻量感

## 色彩建议

- 背景：`#F5F3EF`
- 卡片：`#FBFAF7`
- 主文本：`#1E1F1C`
- 次文本：`#5F6358`
- 边框：`#D8D3CA`
- 强调色：`#6C7A89`

## 字体层级

- H1：40-48
- H2：28-32
- H3：20-22
- Card Title：16-18
- Body：14-16
