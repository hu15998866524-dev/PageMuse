# 测试说明

## 自检范围

- 首页可浏览
- 发现页可浏览
- 分类页可筛选
- 场景页可筛选
- 搜索页可搜索并显示空状态
- 详情页可查看拆解与相似推荐
- 收藏页可创建收藏夹、切换收藏夹、取消收藏、移动收藏

## 当前限制

当前会话环境未安装 `node` / `npm`，因此无法在本地直接执行：

- `npm install`
- `npm run dev`
- `npm run build`

## 建议验证步骤

在安装 Node.js 20+ 的环境中执行：

```bash
cd ppt-inspiration-mvp
npm install
npm run dev
```

然后访问：

```bash
http://localhost:3000
```

## 建议手动检查项

- 卡片 hover 是否生效
- 列表页筛选参数是否正确更新
- 搜索结果是否能按标题、标签、页型、场景命中
- 收藏状态是否写入 `localStorage`
- 不同收藏夹之间移动后是否正确刷新
- 移动端下卡片是否能正常折行展示
